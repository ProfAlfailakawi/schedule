السبب الجذري باختصار
====================
فشل npm run build داخل Docker لم يكن من Docker أو Cloud Run، بل من تدقيق مرشد SCHEDULE.
التدقيق وجد ثلاثة أزرار تفاعلية بلا data-guide-feature-id / data-guide-target أو data-guide-ignore موثق:
1) إعادة بيانات Demo الأصلية.
2) دخول فوري للتجربة في شاشة الدخول.
3) عرض الموعد من الكرت الصغير للقاعة المشغولة.

الحل
====
أضيف data-guide-ignore موثق لكل عنصر لأن هذه العناصر لا تحتاج ميزة مستقلة في المرشد:
- زرا Demo خارج رحلة الاستخدام الأكاديمية الفعلية.
- «عرض الموعد» انتقال ثانوي من معاينة إشغال القاعة إلى تفاصيل موعد قائم، ولا يعدّل بيانات الجدول.

التحقق
======
npm run audit:guide: ناجح
60 ميزة معرفة · 23 هدفًا حيًا · 25 واجهة · 18 إجراءً · 11 رحلة
npm run test:guide: 82 اختبارًا ناجحًا
npm run test:guide:perf: ناجح

ملاحظة بيئة الفحص
=================
npm run build تجاوز تدقيق المرشد والاختبارات ثم توقف محليًا عند vite لأن executable vite غير موجود في node_modules في بيئة الفحص الحالية. هذا ليس نفس خطأ Cloud Build المبلغ عنه؛ الخطأ الثلاثي في Guide Audit أصبح محلولًا.
