السبب الجذري والتعديل — منطق الأوقات + التعريب
==============================================

1) تكرار «سجل 10 سنوات»
كان المصدر التاريخي يظهر في البطاقة كـ sourceLabel، وفي الوقت نفسه كان الحقل article يحمل النص نفسه، لذلك ظهر مرتين. تم فصل اسم المصدر عن نوع المرجع: «السجل التاريخي» + «الاعتياد التاريخي»، ومنع عرض نفس الوسم مرتين.

2) خطأ مدد المحاضرات
كانت هناك قاعدة صريحة خاطئة داخل scheduleRegulations.ts والاختبارات تفترض 60 دقيقة للأحد/الثلاثاء/الخميس و90 دقيقة للاثنين/الأربعاء. هذا لا يطابق نمط البرنامج الفعلي.

المنطق المصحح:
- سجل المقرر نفسه هو المرجع الأول عندما توجد عينة تاريخية كافية.
- تتم مقارنة المدة المختارة بالمدة الأكثر تكراراً للمقرر/نمط الأيام، لا بمجرد نطاق percentile واسع؛ لذلك 11:00–12:30 يحذّر إذا كان المعتاد 11:00–12:20.
- عند غياب تاريخ موثوق فقط: fallback عام 50 دقيقة للأحد/الثلاثاء/الخميس و80 دقيقة للاثنين/الأربعاء.
- التاريخ لا يُستبدل بقاعدة عامة، والقاعدة العامة لا تطغى على تاريخ المقرر.

3) التعريب
استمرت تعديلات التعريب السابقة، ومنها «ليش؟» ← «لماذا؟» والنصوص الإنجليزية الظاهرة للمستخدم.

الملفات المعدلة في هذه الحزمة
-----------------------------
- src/components/Schedules.tsx

- tests/run-tests.ts
- بالإضافة إلى ملفات التعريب السابقة الموجودة في نفس حزمة الإصلاح.

ملاحظة تحقق
-----------
تعذر تشغيل TypeScript build الكامل في بيئة الفحص بسبب نقص type definitions/dependencies المثبتة محلياً، وليس بسبب خطأ مثبت في هذه الملفات. لم يتم رفع أي شيء إلى GitHub أو Cloud Run.
