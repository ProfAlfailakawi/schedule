النطاق:
- تنفيذ بصري فقط، بلا تغيير في منطق الجدولة أو صلاحيات المستخدمين أو APIs أو الحفظ أو الاستيراد أو النشر أو الذكاء.
- المحافظة على الوظائف الحالية كما هي.
- اعتماد icon-first بدل الرموز النصية المبعثرة، مع إبقاء النص الذي يحمل معنى وظيفياً أو قراراً حساساً.

ما نُفّذ:

2. تثبيت العزل البصري للأوقات والأرقام اللاتينية داخل RTL.

4. استبدال ×/✕ النصية بأيقونة X في البحث والتفاصيل والمصفاة حيث كانت ظاهرة للمستخدم.
5. استبدال النقاط النصية التي تعمل كحالة/هوية بأيقونات فعلية أو glyph CSS.
6. استبدال الأسهم النصية الزخرفية في التنقل/المقارنات بأيقونات Lucide في المواضع البصرية الرئيسية.
7. إعادة صقل الكليات والأقسام والمقررات والأساتذة والفصول ضمن master/detail icon-first.
8. إعادة ضبط RecordCard بحيث لا يختفي identifier مهم بسبب قواعد display:none العامة.
9. إضافة glyph للرقم الأكاديمي في MetaPill بدل الاعتماد على label نصي صغير.
10. تحويل حركة المباني إلى صف بصري مبنى ↔ مبنى بأيقونة حقيقية.
11. صقل Dashboard مع هرمية أهدأ للمؤشرات والمقارنات والأيقونات.
12. صقل خزنة الإدارة والبطاقات الحساسة بصرياً مع حصر النص المساعد دون إخفاء التحذير الوظيفي.
