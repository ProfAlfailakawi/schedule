# مصفوفة مراجعة توحيد الاستبيان في «مساري»

تاريخ المراجعة: 2026-10-16  
النطاق: نص المهمة الشاملة + الملحق الإلزامي، ومصدر العمل `main` عند `f23a89e`، ثم التغييرات المحلية في فرع `codex/masari-survey-unification`.

هذه المصفوفة تميّز وجود الوظيفة عن نقلها فعلًا إلى «مساري». لا تعني كلمة «موجودة» أن الوظيفة اجتازت جميع شروط القبول أو حمل الاختبارات الإنتاجي.

| اختبار بصري واقعي للجوال والكمبيوتر | لا تضمن اختبارات المصدر صورة واجهة فعلية | **غير منفذ بعد لهذه المهمة** |

| نشر/ترحيل بيانات الإنتاج | لم يتم | **ممنوع دون موافقة صريحة** حسب نص الملحق |

## قرار القبول الحالي

لا يمكن إعلان إنجاز المهمة الشاملة بعد. أُصلحت داخل مساري إمكانية اختيار المقرر غير المطروح، وأضيفت نقطة دخول لمتابعة الحالات الخاصة بالطالب عبر جلسة آمنة، لكن العناصر التالية ما زالت مانعة للقبول:

1. إنشاء ورفع حالات الفتح/التعارض/التخرج من داخل مساري عبر نفس سجل `StudentNeed`، دون إعادة طلب الهوية ودون ازدواجية.
2. توحيد رغبات مساري وحالات الاستبيان في طبقة تحليل واحدة، مع منع عدّ الطالب/المقرر مرتين وإسناد المقرر لقسمه المالك.
3. جعل توصيات إصلاح/فتح الشعب قادرة على استخدام بيانات مساري نفسها وتقديم أثر جماعي معاد محاكاته.
4. تمكين الطالب من تعديل الشعبة ضمن خطته الشخصية وإعادة حساب التعارض والفراغات فورًا دون حفظ جدول القسم.
5. اختبار تكاملي لرفع صحيفة التخرج والتحقق والموافقة والقرارات عبر الرحلة الموحدة، واختبار بصري وحمل ممثل.

لم تُحذف وظائف `/q` أو `/m`، ولم تُرحّل أو تُعدّل بيانات حية. لا تُعتمد هذه المصفوفة كإقرار جاهزية إنتاجية؛ هي خريطة تنفيذ وفجوات مبنية على الملفات التي راجعتها.
