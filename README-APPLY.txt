SCHEDULE — حزمة إصلاح ملاحظات 2026-09-21
=========================================

هذه الحزمة ليست المشروع كاملاً، ولا تحتوي مجلد wrapper، ولا تحتوي أي خطوط.
ولا تنفذ git commit/push/deploy/upload.

طريقة التطبيق
-------------
1) فك ZIP في أي مكان.
2) من جذر مشروع schedule الحالي شغّل:

   node /path/to/apply-fixes.mjs

3) ثم شغّل التحقق:

   node /path/to/verify-fixes.mjs

4) وبعدها اختبارات المشروع المعتادة:

   npm run lint
   npm test
   npm run build

ما تعالجه الحزمة
----------------
- بطاقتي: رابط الأستاذ يعتبر الفصل الذي أُصدر له هو الفصل التشغيلي؛ إنشاء فصل أحدث للتخطيط لا يجعله للقراءة فقط.
- توحيد خط Plex Arabic في الواجهة العامة وفي الصفحات المنفصلة (بطاقتي والاستبيان)، وإلغاء synthetic weights/tracking السلبي للعربية.
- عزل القسم: لا تظهر أسماء أو تفاصيل قسم آخر داخل شاشة تقرير قسم واحد. يبقى فحص التعارضات الداخلي فعالاً لحماية القاعات.
- حذف عدّاد «ملاحظة لائحية» المكرر من شريط الاعتماد، مع إبقاء البطاقة الأصلية في شاشة التغييرات/الاعتماد.
- طباعة مراجعة الاعتماد تستخدم shell طباعة الاستعلامات نفسه.
- احتواء بطاقات تقرير الأسبوع ومنع النص/الأكواد من الخروج من الإطار.
- حماية معنى التبديل الموجود حالياً: «ما تحرّك» = إضافة/حذف/تعديل فقط، و«الجدول كامل» = كل المقررات.
- لا نعيد كتابة منطق دور رئيس القسم/العميد الموجود حالياً؛ الحزمة تتحقق أن مسار الجدول/الوارد المشترك ما زال محفوظاً.

ملاحظة مهمة
-----------
الحزمة Fail-Fast: إذا تغيّر الريبو بعد النسخة التي روجعت ولم تعد المقاطع المتوقعة موجودة، تتوقف ولا تحاول ترقيع ملف مختلف بصمت.
