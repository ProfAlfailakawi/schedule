تحديث الواجهة — طريقة الرفع
=============================

مهم: هذه الحزمة تُفَك **فوق** مجلد المشروع (دمج)، ولا تُستخدم كاستبدال كامل للمساحة.

خطوات الرفع
-----------
1. فك ضغط الملفات فوق مجلد المشروع مباشرة (نفس المسارات، بدون مجلد إضافي).
2. لا تحذف هذه المجلدات إن كانت موجودة عندك:
      database/     ← نسخة البيانات (db.json.gz)
      node_modules/ ← يُعاد بناؤه في النشر
      dist/         ← يُعاد بناؤه في النشر
      tests/  scripts/  docs/  .github/
3. ارفع كالمعتاد إلى AI Studio / Cloud Run.

لماذا حزمة كاملة للمصدر هذه المرة؟
----------------------------------
الحزمة السابقة كانت «الملفات المعدّلة فقط». الاستيراد في AI Studio قد يعامل
الأرشيف كاستبدال للمساحة، فتختفي ملفات لم تكن داخل الأرشيف، ويفشل البناء بعد
الرفع — وهذا يفسّر توقّف الموقع. هذه الحزمة تحتوي على شجرة المصدر كاملة
(src + public + server.ts + ملفات البناء) بحيث لا يمكن أن تصل «نصف مطبّقة».
قائمة الملفات التي تغيّرت فعلياً في هذه الجولة موجودة في: MODIFIED-FILES.txt

بعد الرفع
---------
- إن ظهرت شاشة بيضاء لمستخدم كان مفتوحاً له الموقع قبل التحديث، فالصفحة تُصلح
  نفسها تلقائياً الآن: تمسح الذاكرة المؤقتة وتعيد التحميل مرة واحدة.
- تأكد أن متغير البيئة NODE_ENV=production في بيئة التشغيل حتى يُخدَم ناتج
  البناء من مجلد dist بدل تشغيل خادم التطوير.

فحوصات نُفِّذت قبل التسليم
-------------------------
  npm run lint      → بدون أخطاء
  npx tsx tests/run-tests.ts → 2004 اختبار ناجح، 0 فاشل
  npm run build     → بناء ناجح (vite + esbuild)
  تشغيل dist/server.cjs مع NODE_ENV=production → الصفحات والملفات تُخدَم 200
